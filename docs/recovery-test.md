# 崩溃恢复测试

## 场景

1. **编辑中崩溃**：未提交的输入通过本地缓冲恢复，已提交 Revision 不丢失
2. **队列执行中崩溃**：任务状态恢复为 pending，重启后继续执行
3. **同步中崩溃**：outbox 未标记 delivered，重连后重传
4. **模型调用中崩溃**：AgentRun 标记为 failed，不产生部分 Patch

## 验证方法

```bash
# 运行测试
cargo test --workspace

# 手动测试：kill -9 后重启，验证
# 1. 章节内容完整
# 2. 任务队列恢复
# 3. 事件日志可回放
```
