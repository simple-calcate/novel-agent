# 示例：第一章 雾港来客

这是按[写作协议](../writing-protocol.md)写完的一章。软件空着的时候，点 **打开示例章节**，就会装进作品「夜航星图」，并预置结构库里的林默、雾港码头、怀表来历。思考里的 `@人物：林默` 仍然只是标签，不是入库。

源文件：`apps/client/src/editor/examples/fog-harbor.json`。改协议时，请让这份样章和导出测试一起过。

读者只会看到正文。淡紫色思考、`@人物` 这些标签，都是写给自己和下一段用的。

## 作者眼里的这一章

一共三拍。每一拍都是：**先想清楚这段要干什么，再写读者看见的字。**

### 第一拍 · 开篇

思考：

```
意图：港口第一眼就要冷，把「有人在等」压到段末
约束：只写林默所见；雾的来源本章不解释
手法：短句，先环境后人物
兑现：潮声、雾、旧怀表
禁止：开场内心独白超过两句
@人物：林默
@地点：雾港码头
@道具：旧怀表
```

正文：

> 雾先于潮声漫进港口。石阶湿了一圈，铁索上结着一层薄盐，灯笼的光到不了这边。林默站在窗前，把那只旧怀表攥在掌心里。盖沿的铜锈蹭在指腹上，像有人刚刚摸过。

`@人物：林默` 只是点名。它不是把林默写进设定库。以后要拆成工具调用，可以再拆；现在标签就是标签。

### 第二拍 · 表盖两个字

思考：

```
意图：让表盖内侧的两个字入镜，但不解释含义
约束：林默此时不知道表是谁留的
手法：动作带出物件，不写说明文
兑现：表盖内侧两个字入镜
禁止：对白里提起亡父姓名
@伏笔：怀表来历
@道具：旧怀表
```

正文：

> 他把表盖掀开一条缝。内侧刻着两个字，笔画浅得像被潮气咬过。灯火一晃，那两个字又隐回去了。林默没有再掀第二次。潮声一下一下敲着船帮，像有人在下面用指节敲门。

### 第三拍 · 灯笼与袖口

思考：

```
意图：远处有人把灯笼掏出来，但不让读者看清脸
约束：来人身份本章不揭
手法：只写袖口和光，把脸留给雾
@人物：林默
```

正文：

> 远处有人把灯笼从帆布里掏出来。光只照见一只袖口，脸仍埋在雾里。林默把怀表收回衣襟，没有出声。石阶上很快只剩潮声，像那个人已经走远，又像从未离开。

## 导出后变成什么样

默认会带走这三拍，都是完整的「思考 + 正文」。

**第一拍**的上文是空的，指令是：

```
写下《第一章 雾港来客》的开篇。
```

助手要生成的是第一拍的思考和正文。

**第二拍**的上文从章首排下来，历史思考标成 `【思考】`，正文原样。当前这一拍的思考不在上文里——那是它自己要写的。

用户侧大致是：

```
【思考】意图：港口第一眼就要冷，把「有人在等」压到段末
约束：只写林默所见；雾的来源本章不解释
…
雾先于潮声漫进港口。石阶湿了一圈，铁索上结着一层薄盐，灯笼的光到不了这边。林默站在窗前，把那只旧怀表攥在掌心里。盖沿的铜锈蹭在指腹上，像有人刚刚摸过。

续写下一段。
```

助手侧：

```
<think>
意图：让表盖内侧的两个字入镜，但不解释含义
…
@伏笔：怀表来历
@道具：旧怀表
</think>

他把表盖掀开一条缝。
…
```

第三拍同理：上文是第一拍和第二拍的全部内容，再写「续写下一段。」

## 不要这样写

下面这种不算完整的一拍，导出时带不走：

```
（没有思考）
林默拔剑。此处待加打戏。
```

缺思考、作者注写进正文，都会被丢掉。补一句「这段要干什么」，再写读者看见的字。
