# 作者保证

给写小说的人看。不是开源声明。

## 稿子在哪

- 正文、结构、队列默认只在本机 SQLite。
- 没配模型、没联网，也能改正文。
- 同步若以后提供，默认关闭。打开前会说明传什么。云端设计是端到端加密、不存明文正文。
- API Key 进系统密钥链（或本机 0600 文件），不进作品库，不进导出。

## 停订以后

付费项（同步、托管模型、插件商店等）到期后，**必须仍能打开、编辑、导出本机已经有的稿**。这是许可里对发行方的约束，不是口头承诺。

## 导出

可以导出 TXT / Markdown。不要把唯一一份稿只留在专有格式里。

## 插件

打包插件默认走内置执行器。第三方模块要权限（读选区、出网、调模型）会写在清单上；沙箱没有文件系统、没有 WASI。用 `@novel-agent/plugin-compile` 编出来的 WASM 也受同一套限制。Android 首版不跑第三方 WASM。

未签名的插件以后可以拒绝加载。现在还没有商店。
