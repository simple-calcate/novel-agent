# 墨枢写作协议 v2

这是给**网文作者**用的写法约定。软件按这个存，以后 AI 续写也按这个学。你日常只要记住一件事：

**思考是写给自己看的便签，正文是写给读者看的小说。**

协议写在写作界面里，不是让作者去读这篇文档：

- 打开章节，编辑器**上方那条**会告诉你此刻该写思考还是正文。
- 空行按 `Tab`，软件自动写下 `意图：`，你补完「这段要干什么」。
- 思考状态下可以点「不能写什么 / 怎么写 / 必须出现 / 这段别写」。
- 思考里输入 `@`，点人物、伏笔、地点、道具、势力、规则。那是**写作标签**，先不必对上设定库。
- 右侧「这一段怎么写」是三步口令。
- 点导出，会用白话告诉你带走了几段、哪几段因为没写思考而没带走。

技术细节（导出格式、分级）见后文。决策记录：[ADR 0009](architecture/adr/0009-writing-protocol.md)。

## 作者怎么用

打开一章，默认就是在写**正文**——读者将来读到的字。

写不顺、或下一段有讲究时，空行按 `Tab`（或行首输入 `>> `），切到**思考**。在淡紫色块里写一句给自己的话，例如：

> 这段先让读者觉得怀表有秘密，先别揭是谁留的。

需要点名时，输入 `@`，选「人物」再补名字，写成 `@人物：林默`。这只是你给这一段贴的标签，不是把角色写进数据库。

写完，再 `Tab` 或 `Mod-Enter` 回到正文，把小说写出来。读者永远看不到思考块。

建议一小段一小段来：**想一下 → 写几句 → 再想一下**。不要章首先写三千字大纲，再一口气写完全章。

| 写在思考里 | 写在正文里 |
|---|---|
| 「这一段不要剧透」 | 角色心里想什么 |
| 「先写雾，人放到最后」 | 对白、动作、景物 |
| 「怀表内侧两个字得出镜」 | 实际写出那两个字 |
| `@人物：林默` `@伏笔：怀表来历` | 林默这个人实际出场、做事 |

不要把 `（作者注：这里加打戏）` 写进正文。那是给你自己看的，放思考里。

以后点 AI 续写，它会从**本章开头**读起：前面写过的思考和正文都会带着，不会只截一段正文。当前这一拍你还在写的思考，仍然只属于这一拍，不会先塞进「上文」让它抄作业。

---

下面是给软件/导出用的同一套规则，作者不必背。
实现：`crates/domain/src/protocol.rs`，前端镜像 `apps/client/src/editor/protocol.ts`。

## 1. 为什么要协议

网文训练数据最常见的失败不是「字不够」，而是**层没切开**：

- 作者备注混进正文，模型学会对读者说话像写大纲。
- 思考写成人物内心独白，模型把「作者意图」当成「角色心理」。
- 只有正文、没有思考，看不出这一拍为什么这样写。
- 有思考但导出时 human 侧写死「继续写作」，模型学不到「根据上文续写」。
- 写完正文再补一句「这一段是铺垫」，那是事后解释，不是写作时的决策。
- 上文只截一段正文、丢掉历史思考，模型看不到本章已经做过的取舍。

协议的目标：让每一条导出样本都接近真实续写任务——**从章首读到光标前 → 想这一拍 → 写出读者可见的正文**。

## 2. 两层文档，三层粒度

| 层 | 读者 | 允许写什么 | 禁止写什么 |
|---|---|---|---|
| **正文 Body** | 书的读者 | 叙事、对白、景物、角色内心 | 作者备注、大纲、TODO、正史补丁 |
| **思考 Thinking** | 作者与模型 | 这一拍的创作决策、写作标签 | 可直接发表的段落、角色对白草稿 |

编辑器只有这两种块。第三种单位是导出时**派生**的，不单独落库：

**拍 Beat** = 连续思考块 + 紧随其后的连续正文块。

拍是训练原子。章是发表单位。作品是正史单位。

```
章
 └─ 拍 1  思考（意图/约束/手法，可含 @标签） → 正文（一段或数段）
 └─ 拍 2  思考 → 正文
 └─ 拍 3  思考 → 正文
```

不要把一整章思考堆在章首、再一口气写完全章正文。那种样本教模型「先写完大纲再喷字」，续写时对不上光标位置。

## 3. 思考写什么：五个槽位

思考是**给下一拍正文用的决策**，不是读后感，也不是设定百科。

推荐行首标签（全角/半角冒号均可）。没有标签的行算自由备注，仍可导出，但进不了金标。

| 槽位 | 标签 | 写什么 | 示例 |
|---|---|---|---|
| 意图 | `意图：` / `目标：` | 这一拍在情节上要完成的一件事 | `意图：让读者感到怀表有秘密，但不揭晓` |
| 约束 | `约束：` / `限制：` | 正史、POV 知情范围、不能剧透 | `约束：林默此时不知道表是谁留的` |
| 手法 | `手法：` / `写法：` | 视角、节奏、钩子、信息释放 | `手法：动作带出物件，不写说明文` |
| 兑现 | `兑现：` / `必须：` | 正文里必须出现的信息或动作 | `兑现：表盖内侧两个字入镜` |
| 禁止 | `禁止：` / `勿：` | 这一拍明确不要写的 | `禁止：对白里提起亡父姓名` |

**最低可用思考**：至少一句意图，能回答「这一拍为什么存在」。
不要把五个槽位写成填空表；用不到的槽位省略。

好的思考：

```
意图：港口第一眼就要冷，把「有人在等」压到段末
约束：只写林默所见；雾的来源本章不解释
手法：短句，先环境后人物
兑现：潮声、雾、旧怀表
禁止：开场内心独白超过两句
@人物：林默
@道具：旧怀表
```

坏的思考（不要这样，导出时会降级或丢弃）：

- 「写得好看一点」（没有可执行决策）
- 把下一拍正文先写在思考里再复制到正文（泄漏）
- 「林默心想：这雾不对劲」（角色内心应在正文）
- 粘贴人物小传、地图设定（那是正史/浮带，不要把百科贴进思考）

## 4. 正文写什么

正文是发表面。导出时只把 Body 块拼成 `content`。

禁止出现：

- `（作者注…）` `【作者…】` `TODO` `FIXME` `此处待`
- 行首 `意图：` `约束：` `伏笔：`（槽位写错层了）
- 行首 `>> `（思考快捷键残留）

角色心里想什么写在正文，作者想怎么写写在思考。

## 5. 操作约定（编辑器）

这些按键就是「拍」的边界，不要改语义：

| 操作 | 含义 |
|---|---|
| 空行行首 `Tab` | 切换思考 / 正文（新拍的边界） |
| 行首 `>> ` | 本段转为思考 |
| 思考行首 `<< ` 或 `Mod-Enter` | 结束思考，开始本拍正文 |
| 思考块内 `Enter` | **同一拍**的下一行思考，不是新拍 |
| 思考内 `@` | 插入写作标签（人物 / 伏笔 / 地点 / 道具 / 势力 / 规则） |

写的顺序应尽量是 **思考 → 正文 → 下一拍思考**。先写正文再补思考，样本只能当银标或丢弃：那是事后解释，模型学不会「先决策再落笔」。

## 6. 写作标签

思考里的 `@` 点的是**书中预先设好的词表**，不是正史实体行。

内置种类：

| 种类 | 作者补什么 | 示例 |
|---|---|---|
| 人物 | 角色名 | `@人物：林默` |
| 伏笔 | 这条伏笔怎么称呼 | `@伏笔：怀表来历` |
| 地点 | 地名 | `@地点：雾港码头` |
| 道具 | 物件名 | `@道具：旧怀表` |
| 势力 | 组织名 | `@势力：巡潮司` |
| 规则 | 世界规则怎么称呼 | `@规则：潮声能传讯` |

约定：

1. 标签身份就是 `kind + label`。`id` 可空，留给以后的目录。
2. 标签不等于 `CanonEntity`。后期可以把同一条标签拆成详细工具调用，现在不要绑数据库主键。
3. 导出时若思考正文里已经写了 `@人物：林默`，不再另贴一份 `[摘要]`。全角/半角冒号视为同一条。
4. 旧的任务 / 设定 / 自定义标记仍可反序列化，新插入默认走 `Tag`。

## 7. 训练样本长什么样

**一条拍级样本**（默认导出粒度）：

```
context      本拍之前、从章首排下来的全部内容。思考前加【思考】，正文原样。不截断。开篇可为空。
instruction  开篇：「写下《章名》的开篇。」；否则：「续写下一段。」
thinking     本拍思考（含尚未写进正文的标签摘要）
content      本拍正文
quality      gold | usable | skip
```

对应到续写任务：

```
（系统，稳定短指令）
你按墨枢写作协议写网文：先思考本拍决策，再写读者可见正文。
思考不是人物内心独白，正文不含作者备注。
思考里的 @人物/@伏笔 是写作标签，不必当成数据库实体。

（用户）
【思考】意图：让读者感到怀表有秘密，但不揭晓是谁留的
林默站在窗前。雾已经漫过码头的铁索……

续写下一段。

（助手）
<think>
意图：让表盖内侧的两个字入镜，但不解释含义
@道具：旧怀表
</think>

他把表盖掀开一条缝。
```

硬规则：

1. **当前拍的思考不得出现在用户侧。** 意图属于模型要生成的内容，写进 prompt 会变成抄作业。
2. **上文从章首累积，含历史思考和正文，不截断。** 历史思考用 `【思考】` 标出来，避免和正文混层。v1 曾规定上文只含正文；v2 改掉，因为续写要对齐「从章首读到光标」。
3. **不要用「继续写作」当 human。** 那是零信息指令，会污染所有样本。
4. **缺思考的正文默认不进训练集。** 需要纯正文样本时显式 `minQuality=skip`。
5. **章末悬空思考（有思考无正文）不是样本。** 未完成的拍不导出。
6. 章级样本（整章思考+整章正文）与拍级样本分文件存放，不要混在同一 jsonl。v2 只导出拍级。

## 8. 质量分级

导出器按下面打分，默认只写出 `gold` + `usable`。

| 级 | 条件 |
|---|---|
| **gold** | 有 `意图` 槽；思考 ≥ 16 字；正文 ≥ 40 字；思考不是正文的拷贝；正文未混入作者备注 |
| **usable** | 有非空思考 ≥ 8 字；正文 ≥ 24 字；无严重串层 |
| **skip** | 无思考；过短；思考被整段贴进正文；正文像大纲/作者注；拍不完整 |

串层检测（命中则 skip）：

- 思考全文是正文的子串，或正文是思考的子串（≥ 16 字）
- 正文出现作者注、TODO、行首槽位标签

金标不是「五个槽位填满」，而是「有可执行意图、两层没串、长度够续写」。

## 9. 导出格式

`training.export` 与编辑器导出共用同一套分级：

| format | 用途 |
|---|---|
| `jsonl` | 原生字段最全，后续自己转换 |
| `sharegpt` | 对话：system + human(context+instruction) + assistant(`<think>`+正文) |
| `alpaca` | `instruction` / `input`(上文) / `output` |
| `r1` | `<think>…</think>` + 正文，样本之间 `---` |

默认 `minQuality=usable`。`includeMarkup` 默认 true。`protocolVersion` 为 2。

## 10. 给作者的十条

1. 一拍一事。意图里只放一个情节功能。
2. 思考写「为什么 / 不能怎样」，正文写「看见什么」。
3. 约束只写**这一拍会踩到的**，不要贴人物全传。
4. 伏笔用兑现/禁止或 `@伏笔`，不要在正文里用括号提醒自己。
5. 先思考后正文；改正文时顺手改思考，否则下一拍的决策是假的。
6. 不要把续写 AI 的输出原样当思考——那是正文候选。
7. 开篇第一拍也要有思考（基调、信息延迟、钩子），不要「正文从零开始」。
8. 对话多的段落，思考里写目的（试探、隐瞒、翻脸），不要预写对白。
9. 同一拍思考用 Enter 换行；下一拍先 Tab 回思考，不要在正文中间夹一句作者嘴。
10. 导出后看那句白话说明：没带走的段落，补一句思考再导出，不要事后批量编造。

## 11. 给模型的系统短指令（导出时写入）

后续改措辞必须同步 `WRITING_PROTOCOL_SYSTEM` 常量，避免训练/推理各用一套。

```
你按墨枢写作协议写网文：先思考本拍决策，再写读者可见正文。思考不是人物内心独白，正文不含作者备注。思考里的 @人物/@伏笔 是写作标签，不必当成数据库实体。
```

## 12. v2 刻意不做的

- 不为思考做强制表单。标签是约定，解析在导出时做。
- 拍不单独建表。边界由块序列派生，避免作者维护第三套结构。
- 不做每书自定义标签目录、也不把 `@` 绑到正史实体 id。标签先保持词表身份，以后再拆工具调用。
- 暂不把正史快照打进每条样本。正史走浮带与装配，等正史审核稳定再并入 jsonl。
- 不记录「思考是否写在正文之前」的时间戳。用内容特征近似；需要金标时靠作者习惯与人工抽检。
