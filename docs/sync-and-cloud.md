# 同步与云功能设计

## 阶段 1（当前）

- 本地 SQLite 是唯一数据源
- 手动导出 TXT/Markdown
- 自动备份到本地目录
- outbox 可追加写成应用数据目录下的 JSONL（工作流页「写出 journal」）。**不是**设备间同步。

## 阶段 2（设备同步）

- 端到端加密的设备间同步
- 传输幂等 outbox 变更
- 冲突时保留冲突副本，UI 提供合并工具
- 云端不存储明文正文

## 阶段 3（商业控制面）

- 许可/订阅验证（到期不得锁本机正文，见 [trust.md](wiki/trust.md)）
- 插件签名与审核
- 可选匿名诊断（默认关）
- 隐私设置中心
- 宿主专有、插件接口 MIT，见 [ADR 0012](architecture/adr/0012-host-proprietary-plugin-mit.md)

## 实时协作（立项后）

- 按章节引入 Yjs/CRDT
- 云端中继，不成为本地写作的可用性前提
