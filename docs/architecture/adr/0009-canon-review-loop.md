# ADR 0009: 正史候选确认闭环

## 状态
已接受

## 背景
[ADR 0003](0003-story-model.md) 规定：抽取只生成候选，作者确认后进入正史。此前仓储只有正史读取、没有写入，浮带会匹配库里的全部事实。

## 决策
- 从当前章节用确定性启发式（说话人、`《书名》`、走进/来到地点）生成 `CanonFact`，状态为 `candidate`。
- 作者在右侧「正史」面板接受或拒绝。接受后状态为 `accepted`。
- `context.hints` 与 `continuity.check` 以及 FTS 重建只使用**已接受**且属于当前作品的事实。
- 首版不调用 LLM。启发式可被后续模型抽取替换，但写入路径不变：永远先候选、再确认。

## 后果
- 误抽不会污染浮带。
- 需要作者点一次「从本章提取」；未打开章节时按钮禁用。
- 仓储按聚合拆到 `repository/{library,revisions,canon,queue,automation}`，避免单文件继续膨胀。
